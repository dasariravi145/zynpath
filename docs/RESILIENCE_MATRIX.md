| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

| **Daily Challenge** | Process death during attempt | Resume option if within same UTC day | Snapshot preserved if valid for today's UTC date | None | Local Room DB + UTC clock | Resume puzzle attempt | **IMPLEMENTED (DEFERRED TO FINAL TESTING)** |
