# Google Play Console Upload & Release Procedure

## 1. Prerequisites & Account Setup

> [!IMPORTANT]
> **Action Status: REQUIRES MANUAL PLAY CONSOLE ACTION**
> Cloud console operations, app creation, and release publishing cannot be automated without authorized Play Developer API credentials and explicit account owner consent.

### Required Account Assets:
1. **Google Play Developer Account:** Active, verified developer account in good standing.
2. **Application Profile:** Created application named `Zynpath: Number Path Puzzle` with package name `com.zynpath.game`.
3. **Google Play App Signing:** Enrolled via **App Integrity** using Google-managed key.
4. **Content & Store Compliance:** Store listing details, privacy policy URL, and Data Safety questionnaire completed.

---

## 2. Release Track Progression Workflow

```
[Internal Testing] ──> [Closed Testing (20 Testers / 14 Days)] ──> [Production (Staged Rollout)]
```

### Stage 1: Internal Testing Track
- **Audience:** Core developers and internal QA team (up to 100 email invites).
- **Availability:** Instant (no Google Play review queue).
- **Purpose:** Validate installation, license testing purchases, WebSocket connectivity to `api.zynpath.app`, and Room database migrations.

### Stage 2: Closed Testing Track
- **Audience:** Selected external test group.
- **Requirement:** For personal developer accounts created after Nov 2023, Google Play requires at least **20 testers opted-in for at least 14 days continuously** before applying for production access.
- **Purpose:** Gather crash diagnostics, verify battery/memory consumption on diverse hardware, and satisfy Google Play release requirements.

### Stage 3: Production Track
- **Audience:** Public Google Play Store users.
- **Rollout Strategy:** Staged rollout starting at 10% → 25% → 50% → 100% per [RELEASE_ROLLBACK.md](file:///d:/Zynpath/docs/RELEASE_ROLLBACK.md).

## 3. Step-by-Step Manual Upload Procedure

1. **Download Verified Artifact:**
   Download `app-release.aab` and `app-release.aab.sha256` generated by the GitHub Actions `release-bundle` job.
2. **Verify Checksum:**
   ```bash
   sha256sum -c app-release.aab.sha256
   ```
3. **Navigate to Play Console:**
   Select **Zynpath: Number Path Puzzle** → **Release** → **Internal testing** (or target track).
4. **Create New Release:**
   Click **Create new release**.
5. **Upload App Bundle:**
   Drag and drop `app-release.aab`. Verify the console detects:
   - Package Name: `com.zynpath.game`
   - Target SDK: `36`
   - Minimum SDK: `24`
   - Native Platforms: `arm64-v8a`, `armeabi-v7a`, `x86_64`
6. **Upload Mapping File (if not embedded):**
   Under **App bundle explorer** → **Downloads** → **Assets**, verify `mapping.txt` is registered.
7. **Input Release Notes:**
   Paste the localized `<en-US>` release notes from [RELEASE_NOTES_TEMPLATE.md](file:///d:/Zynpath/docs/RELEASE_NOTES_TEMPLATE.md).
8. **Review & Save:**
   Click **Next** to review pre-launch report checks and warnings.
9. **Send for Review:**
   Confirm release submission.
